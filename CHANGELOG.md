# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-15

### Added
- ✨ Initial release of Family Tree application
- 👤 User authentication system with secure password hashing
- 📝 Complete family member management (CRUD operations)
- 👨‍👩‍👧‍👦 Family relationship tracking (father, mother, spouse, children)
- 📸 Photo upload functionality with automatic image resizing
- 🌳 Interactive family tree visualization
- 🔍 Search functionality for family members
- 📊 Dashboard with family statistics
- 🎨 Responsive design with Bootstrap 5
- 🔒 User authentication and authorization
- 📱 Mobile-friendly interface
- 🗄️ SQLite and PostgreSQL database support
- 🚀 Ready for production deployment
- 🐳 Docker configuration for containerized deployment
- 📖 Comprehensive documentation and setup guides

### Features
- User registration and login
- Add, edit, and delete family members
- Upload and manage family photos
- Track family relationships and hierarchy
- View family tree visualization
- Search and filter family members
- User profile management
- Responsive Bootstrap 5 design
- Dark mode support planned

### Technical
- Flask 2.3.3 web framework
- SQLAlchemy ORM for database
- Flask-Login for authentication
- Pillow for image processing
- Bootstrap 5 for responsive UI
- Gunicorn for production server
- Railway and Heroku deployment ready
